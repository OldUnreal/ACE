1) Installation
---------------

The package contains one folder per architecture: System (32-bit), System64
(x86-64) and SystemARM64 (Linux ARM64). How you copy them depends on your UT
version:

* UT 469f and newer keep all files in a single System folder. Copy the
  contents of the package's System folder into your server's System folder.
  On a 64-bit server, then copy the contents of System64 (x86-64) or
  SystemARM64 (ARM64) over it, replacing files with the same name. Copy System
  first: System64 and SystemARM64 do not contain every package.

* UT 469e and older use the same folder layout as this package. Unzip the
  package into your server's UT folder as is.

*******************************************************************************
****************** UPGRADING FROM A PREVIOUS ACE INSTALLATION *****************
*******************************************************************************

* Install the files as described above. Make sure that the Logs and Shots
folders are created!

* Open your server's ini file (UnrealTournament.ini, or the file passed with
ini= on the command line) and browse to the [Engine.GameEngine] section.

* Remove all ServerActors and ServerPackages for previous ACE and NPLoader
  packages.

* It is recommended to delete the previous ACE version's files from your
  server's System folder(s) before rebooting. At the very least, remove the
  old NPLoader int file (e.g. NPLoader_ACEv14d.int) and the old ACE packages
  and libraries (e.g. ACEv14d_S.u, ACEv14d_S.so, ACEv14d_S.dll,
  ACEv14d_C.u, ...).

* Add:

  ServerActors=NPLoader_v25.NPLActor

* If you are copying over the ACE settings from a previous installation, please
make sure you delete the FileListProvider and TweakListProvider settings!
  	
* Reboot your server. The rest of the installation is automatic.
  
*******************************************************************************
************************* INSTALLING ON A CLEAN SERVER ************************
*******************************************************************************

* Install the files as described above. Make sure that the Logs and Shots
folders are created!

* Open your server's ini file (UnrealTournament.ini, or the file passed with
ini= on the command line) and browse to the [Engine.GameEngine] section.

* Add:
  
  ServerActors=NPLoader_v25.NPLActor
    
* Reboot your server. The rest of the installation is automatic.

*******************************************************************************

2) Settings
-----------

For most people, ACE will work fine with the default settings. Should
you run any custom mods that perform rendering or input operations and that
are not recognized by ACE, then add the following section to your server's
ini file:

[ACEv14_AutoConfig.ACEAutoConfigActor]
UPackages[0]=
UPackages[1]=

Then add your mod to this list. If you run a mod called MyMod.u for example,
simply add UPackages[0]=MyMod.u. You can add up to 255 packages to this list.

AutoConfig only adds mods that are in the server's package map (normally via
ServerPackages), because the server doesn't make clients load anything else.
On every map it rebuilds the UPackages list under [ACEv14e_S.ACEActor] and
drops entries that are not in the package map. If you set bAutoConfig=false,
AutoConfig does not run and you must maintain that list yourself, using base
names (e.g. UPackages[0]=MyMod).

3) To the mod authors
---------------------

The following packages are open source:

* IACEv14: This package contains the interfaces for many of the ACE classes.
Do NOT recompile this package! It is open source so you can see how it works.

* ACEv14e_EH: This is the ACE event handler. It is very similar to UTDC's
EventActor. You're more than welcome to edit this package and to share your
modifications.

* ACEv14_AutoConfig: This is a small mod that automatically sets up the ACE
UPackages list. Once again, you're more than welcome to edit this.

Mods that are on ACE's UPackages list can add their own file hashes and tweak
list rules by installing an ACEFileList-ModName.txt and/or
ACETweakList-ModName.txt file in the FileListPath/TweakListPath folder. Replace
ModName with the base name of the mod (the file name without extension).

You can use UnrealEd or wotgrealexporter to export the source code from the
.u files or you can download the source code from:

https://github.com/stijn-volckaert/
