1) Installation
---------------

The package contains System (32-bit), System64 (x86-64) and SystemARM64
(Linux ARM64) folders. Copy the files according to your UT version:

* UT 469f and newer: Copy the package's System files into the server's System
  folder first. For a 64-bit server, then copy System64 (x86-64) or SystemARM64
  (ARM64) into the same folder, replacing files with the same name.

* UT 469e and older: Unzip into the server's UT folder, keeping the package's
  folder layout.

Make sure the Logs and Shots folders exist in your UT folder.

*******************************************************************************
****************** UPGRADING FROM A PREVIOUS ACE INSTALLATION *****************
*******************************************************************************

* Copy the package files as described above.

* Open your server's ini file (UnrealTournament.ini, or the file passed with
  ini= on the command line) and browse to the [Engine.GameEngine] section.

* Remove all ServerActors and ServerPackages for previous ACE and NPLoader
  packages.

* It is recommended to delete the previous ACE version's files from your
  server's System folder(s) before rebooting. At the very least, remove the
  old NPLoader int file (e.g. NPLoader_ACEv14d.int) and the old ACE packages
  and libraries (e.g. ACEv14d_S.u, ACEv14d_S.so, ACEv14d_S.dll,
  ACEv14d_C.u, ...).

* Add:

  ServerActors=NPLoader_v26.NPLActor

* If you copy ACE settings from a previous installation, delete
  FileListProviderHost, FileListProviderPath, TweakListProviderHost and
  TweakListProviderPath so ACE uses the current defaults.
  	
* Reboot your server. The rest of the installation is automatic.
  
*******************************************************************************
************************* INSTALLING ON A CLEAN SERVER ************************
*******************************************************************************

* Copy the package files as described above.

* Open your server's ini file (UnrealTournament.ini, or the file passed with
  ini= on the command line) and browse to the [Engine.GameEngine] section.

* Add:
  
  ServerActors=NPLoader_v26.NPLActor
    
* Reboot your server. The rest of the installation is automatic.

*******************************************************************************

2) Settings
-----------

For most people, ACE will work fine with the default settings. Should
you run any custom mods that perform rendering or input operations and that
are not recognized by ACE, then add the following section to your server's
ini file:

[ACEv14_AutoConfig.ACEAutoConfigActor]
UPackages[0]=
UPackages[1]=

Then add your mod to this list. If you run a mod called MyMod.u for example,
simply add UPackages[0]=MyMod.u. You can add up to 255 packages, indexed from
0 to 254. With AutoConfig's PackageHelper enabled, entries are kept only if
present in the server's package map, normally through ServerPackages.

If you disable AutoConfig, maintain the ACEActor list directly using package
base names, without the .u extension:

[ACEv14f_S.ACEActor]
bAutoConfig=false
UPackages[0]=MyMod

See SETTINGS.txt for server and AutoConfig options.

3) To the mod authors
---------------------

The following packages are open source:

* IACEv14: This package contains the interfaces for many of the ACE classes.
Do NOT recompile this package! Rebuilding changes its package GUID and breaks
compatibility with servers using the original package.

* ACEv14f_EH: This is the ACE event handler. It is very similar to UTDC's
EventActor. You're more than welcome to edit this package and to share your
modifications.

* ACEv14_AutoConfig: This is a small mod that automatically sets up the ACE
UPackages list. Once again, you're more than welcome to edit this.

You can use UnrealEd or wotgrealexporter to export the source code from the
.u files or you can download the source code from:

https://github.com/stijn-volckaert/
