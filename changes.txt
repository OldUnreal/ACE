v1.4e:
* [CHANGED] Updated NPLoader (v2.3 -> v2.5). Prompts to reinstall Windows
  libraries when switching between 32-bit and 64-bit UT; files stay in System
* [FIXED] Windows server DLL not loading on Win7 / Server 2008 R2

v1.4d:
* [CHANGED] ACE no longer hijacks the engine main loop. Per-frame checks now
  run via a UGameEngine::Tick wrapper so UT469 raw-input mouse handling keeps
  working on the engine's own loop (Windows and Linux)
* [CHANGED] Removed leftover ACE sleep/appSleep hooks after the Tick wrapper
  change
* [FIXED] Fixed the Core hook count on the server after the sleep-hook removal
* [FIXED] IACEv14 is no longer recompiled on every UnrealScript build. Rebuilding
  it regenerated the package GUID and broke connecting to servers
* [FIXED] Fixed a 64-bit NPLoader bind fatal ("not a DLL package") by installing
  the loader .u into the engine package path (System) instead of the binaries
  directory (System64)
* [CHANGED] Updated NPLoader (v2.2 -> v2.3), including install-then-reconnect so
  natives bind against settled files
* [ADDED] OLDSKOOL.U to the default ACEFileList

v1.4c:
* [FIXED] Fixed a bug that was causing a false positive kick for Editor.dll
* [FIXED] ACE Logo can now be moved using LogoXPos and LogoYPos config settings
* [FIXED] Fixed a bug that was causing OpenAL32.dll to get flagged on 469b clients
* [ADDED] Several small adjustments to reduce timeouts

* [ADDED] ACE Windows x64 server support

v1.4a:
* [ADDED] Native 64-bit Windows client support. ACE now runs natively on 64-bit
  UT clients (System64). The client DLL is automatically selected based on game
  architecture.
* [ADDED] Linux x86/x64 client coverage for UT v469+ clients.
* [ADDED] Windows ARM64 compatibility for players running UT through emulation
  on ARM-based Windows devices.
* [ADDED] Memory reader detection. Detects external tools accessing game memory.
  Disabled by default - see bMemoryReaderDetection in SETTINGS.txt.
* [ADDED] Code injection detection. Detects unauthorized code running in the
  game process. Disabled by default - see bCodeInjectionDetection in SETTINGS.txt.
* [ADDED] Pawn texture verification (brightskins detection). When AntiTweak is
  enabled, ACE checks for texture modifications that make enemies more visible.
  Legitimate effects (UDamage, Invisibility) are automatically excluded.
* [ADDED] Thread watchdog. Additional protection against tampering with ACE's
  scanning. Disabled by default - see bEnableThreadWatchdog in SETTINGS.txt.
* [ADDED] Self-integrity verification.
* [CHANGED] Encryption now uses cryptographically secure random number generation.
* [CHANGED] AntiTweak detection has more coverage
* [CHANGED] Various performance optimizations.
* [CHANGED] Better handling of Windows hot-patches and compatibility shims,
  reducing false positives on modern Windows systems.
* [FIXED] False positive detections on ARM64 Windows.

v1.3a:
* [ADDED] Optional AntiTweak protection. This protection can be enabled by
setting bAntiTweak to 1 under [ACEvXXX_S.ACEActor] in the server ini. The
protection itself can be configured using the ACETweakList.txt file in the
server system folder.

If the protection is enabled, ACE will also automatically download updates for
the tweak list. Auto updates can be toggled on or off using the
bAutoUpdateTweaklist option. You can also set a custom tweak list provider using
the TweakListProviderHost (default value: utgl.unrealadmin.org),
TweakListProviderPath (default value: /ACE/), and TweakListName (default value:
ACETweakList.txt) options.

Finally, you can set a custom storage path for the tweak list using the
TweakListPath option (default value: ../System/).
